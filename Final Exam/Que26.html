Course Structure

First Year (FE)

  • Mathematics I – Basic engineering math
  • Physics – Fundamentals of physics
  • Chemistry – Applied chemistry concepts
  • Basic Programming – Intro to coding

Second Year (SE)

  • Data Structures – Organizing data efficiently
  • OOP – Object-oriented programming
  • Computer Networks – Networking basics
  • DBMS – Database management

Third Year (TE)

  • Operating Systems – Process & memory management
  • Software Engineering – Development lifecycle
  • Web Technologies – HTML, CSS, JS
  • AI – Basics of artificial intelligence

Final Year (BE)

  • Machine Learning – Data-driven models
  • Cloud Computing – Cloud platforms
  • Big Data – Handling large datasets
  • Project Work – Final year project
